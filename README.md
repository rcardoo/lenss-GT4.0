## Objetivo

Criar uma rede social de fotos completa, do zero, e colocá-la no ar com segurança para qualquer pessoa usar.

## Tecnologias

| Camada | Tecnologias |
|---|---|
| Front-end | React 19, Vite, React Router, Bootstrap 6, Swiper, Motion e ícones Lucide |
| Back-end | Node.js, Express 5, JWT em cookie seguro, bcrypt e multer |
| Banco de dados | SQLite (libSQL) no computador e Turso online |
| Nuvem | Vercel, com as fotos no Vercel Blob |
